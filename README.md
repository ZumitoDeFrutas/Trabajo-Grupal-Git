# Viaja Ecuador

Sitio web estático de destinos turísticos de Ecuador, desarrollado en parejas
para la evaluación de Git + GitHub con HTML5 y CSS3.

## Tecnologías

- HTML5
- CSS3
- Git y GitHub

## Instrucciones de uso

1. Clonar el repositorio:
```bash
   git clone <https://github.com/ZumitoDeFrutas/Trabajo-Grupal-Git.git>
```
2. Entrar a la carpeta del proyecto:
```bash
   cd Proyecto Final Git
```
3. Abrir `index.html` en el navegador.
